# Картонное подземелье

Top-down рогалик на Unity в духе Archero: бумажный маг, автоатака, навыки на клавишах **1–5**,
перки после каждой комнаты и постановочные переходы между волнами в картонном подземелье.

Проект в разработке. План и этапы — в [PLAN.md](PLAN.md).

## Управление (план)

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| 1–5 | Активные навыки |
| Space | Рывок / пропуск кат-сцены |
| Esc | Пауза |
